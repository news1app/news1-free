# NEWS1 Free Market Intelligence

NEWS1 Free adalah versi Android + GitHub Actions tanpa OpenAI API dan tanpa backend berbayar.

## Fitur
- market snapshot: XAUUSD/proxy, DXY, US10Y, USDJPY, EURUSD, GBPUSD, Brent, WTI, S&P 500, Dow, Nasdaq, Bitcoin;
- headline 24 jam dari publisher yang diminta ketika terindeks;
- kalender ekonomi 7 hari ketika feed publik tersedia;
- bias XAUUSD, DXY, yield, oil;
- dominant asset, next catalyst, skenario rule-based, confidence;
- deteksi sederhana mengikuti/tertahan/melawan fundamental;
- riwayat lokal Android;
- refresh dan notifikasi berkala;
- GitHub Actions untuk update data dan build APK.

## Tidak memakai
- OpenAI API;
- Render;
- API key;
- scraping isi paywall.

## Start
Baca **START_HERE.txt** lalu **PANDUAN_BAHASA_BAYI.md**.

## Transparansi data
Endpoint publik dapat berubah, rate-limit, atau tidak tersedia. Sistem menampilkan warning/cached/unavailable dan tidak membuat data palsu.
